# 抖音直播画面（皮套 + 弹幕 + 点歌）

一个 1920×1080 的直播画面层：皮套在中间，弹幕从右侧进来，底部走字幕，
观众点歌能自动播。**画面不用浏览器** —— Python + Pillow 直接画，塞进一个
原生 Win32 窗口，直播伴侣用「窗口捕捉」抓它，空闲时只占单核 3%。

```
双击 start.cmd  →  浏览器打开控制台  →  点「开播」  →  直播伴侣选窗口  →  开播
```

---

## 一、它由三块组成

| 块 | 端口 | 干什么 |
|---|---|---|
| **控制台** `server.mjs` | `18082` | 发所有网页、管桥的启停、反代。**桥死了它照样能开** |
| **弹幕桥** `bridge.mjs` | `18081` | 连抖音拿弹幕、送礼、进房；跑话术引擎；出状态给画面 |
| **播放器** `player/musicd.mjs` | `18083` | 点歌：搜歌、取直链、维护队列。声音由网页放 |
| **画面** `native/overlay.py` | — | 原生窗口，不是网页。直播伴侣抓的就是它 |

> 记牢一句话：**18082 是控制台，18081 是桥。** 打不开网页看 18082，
> 网页能开但点「开播」没反应看 18081。

## 二、环境

- **Node.js 18+**（22 也行）。`start.cmd` 会自己找，找不到会告诉你装哪个。
- **Python 3.8+ 且装了 Pillow**。画面是 Python 画的，没有 Pillow 画面秒退
  （而桥照常说话，很容易误判成"环境没问题"）。
- 可选：`imageio-ffmpeg`，只有放礼物视频才需要。

```bash
node -v
python -c "import PIL; print(PIL.__version__)"
```

## 三、跑起来

### 1. 起控制台

双击 **`start.cmd`** —— 黑窗口出现，浏览器自动打开 `http://127.0.0.1:18082/`。
**这个窗口别关**，关了桥也跟着停（Windows 上父进程被杀会带走子进程）。

想手动指定端口：`set ZY_CTL_PORT=18099 && node server.mjs`

### 2. 起画面

双击 **`open-overlay.cmd`** —— 弹出「Dafeiyu 直播画面」窗口，1920×1080。
窗口上按 `Esc` 关掉。

```bash
open-overlay.cmd --demo       # 假弹幕，不连抖音，先看效果
open-overlay.cmd --topmost    # 窗口置顶
```

### 3. 接进直播伴侣

直播伴侣 → 添加素材 → **画面捕捉 → 窗口** → 选「Dafeiyu 直播画面」→ 拖满画布。
尺寸正好 16:9，**不用缩放**。

### 4. 开播

在控制台点「开播」。走的是你自己的账号登录态和实名信息，脚本不碰也不该碰。

## 四、页面都在控制台里

左侧菜单切换，地址栏里的 `#` 可以直接跳到某一页：

| 页面 | 地址 | 用途 |
|---|---|---|
| 控制台 | `#/panel` | 开播、状态、正在播什么 |
| 日志 | `#/logs` | 收发 / 桥日志 / 素材播放，三个页签 |
| 设置 | `#/settings/account` | 十一个页签，见下 |
| 画面 | `#/editor` | 拖组件位置、调宽度，**1 秒内生效，不用重启** |
| 播放器 | `#/music` | 点歌台、队列、音量 |

设置页的十一个页签：**账号 / 形象 / 回复 / 礼物 / 素材 / 音量 / 记忆 / 人格 / 知识 / 音源 / 诊断**。
想直接落在某一页，单独打开 `settings.html#sound` 这种写法也行。

- **回复**页能改两条聊天之间的间隔（默认 2.5 秒，范围 0.5–15 秒，存了当场生效）。
- **音量**页四个旋钮：`voice` 她说话 / `media` 素材视频 / `music` 音乐基准 / `duck` 闪避深度。
- **知识**页能每份库、每一块单独开关，还能试「这条弹幕会捞到哪几块」。
- **画面**页（`editor.html`）**只有 `x / y / w / visible` 可调**，
  高度是按内容倒推的，放开会叠字。

## 五、仓库里有什么

```
zhibo/
├── native/
│   ├── render.py       # 画面合成：Pillow 画整帧，静态层缓存、逐帧只画变量
│   ├── pet.py          # 皮套动作帧播放器
│   └── overlay.py      # 窗口层：ctypes 调 Win32，无 tkinter 依赖
├── bridge.mjs          # 弹幕桥：抖音 MCP → HTTP 快照 + SSE
├── reply.mjs           # 话术引擎：弹幕 → 一句话（人设卡 + 知识库 + 记忆）
├── server.mjs          # 控制台：发网页、管启停、反代
├── player/
│   ├── netease.mjs     # 网易云接口（自己实现的 weapi/eapi）
│   ├── musicd.mjs      # 点歌服务 :18083
│   └── player.html     # 浏览器放音（要一直开着）
├── index.html          # 外壳：左侧菜单 + 常驻播放器
├── panel.html          # 控制台
├── settings.html       # 设置（十一个页签）
├── editor.html         # 画面版式编辑器
├── music.html          # 播放器页
├── logs.html           # 日志页
├── ui/theme.css        # 共用样式
├── prompts/            # 人设卡 / 皮套 / 知识库（**只有模板，自己补**）
├── start.cmd           # 双击起控制台（自动开浏览器）
├── start-bridge.cmd    # 双击只起桥（调试用）
└── open-overlay.cmd    # 双击起画面
```

**不进仓库的**：`assets/`（素材）、`media/`（礼物视频）、`cache/`（运行时配置）、
`cookies.txt`（登录态）、`llm.json`（模型 key）、`.run/`（pid 和日志）。
换机器要自己拷过去。

## 六、第一次用要补的东西

仓库只带**模板**，真实内容得自己写 —— 都在 `prompts/` 下，改完不用重启：

| 文件 | 作用 | 缺了会怎样 |
|---|---|---|
| `prompts/dafeiyu-live.md` | 主角色卡：她是谁、怎么说话 | 回退到内置的八行人设，很薄，容易漂 |
| `prompts/skins/<皮套名>.md` | 这一身长什么样 | 只说「今天穿的女仆装」，被问颜色会编 |
| `prompts/kb/<库名>.md` | 知识库，一份 md 一个库 | 没有知识储备，只能闲聊 |
| `llm.json` | 模型：`mode` / `base` / `key` / `model` | 只能用本地话术 |
| `cache/layout.json` | 画面版式 | 用内置默认坐标 |

格式看 `prompts/README.md`，以及同目录下的 `example.md`。
皮套名对应 `cache/layout.json` 里 `items.character.pet` 的值。

## 七、素材怎么准备

```
assets/
├── pet2/             # 动作帧序列（WebP，714×714，124 帧）—— 默认用这套
├── pet/              # 旧的一套（3444 帧），ZY_PET_DIR=pet 切回去
└── bg.png            # 背景图 1920×1080
media/                # 礼物档位视频（mp4），按档位放
```

- **换素材 = 换比例**，代码常量和版式要一起改。`layout.json` 每 0.5 秒热读，
  但 `render.py` 的常量不热更 —— 换素材后要重启画面进程。
- 背景图有深浅两套配色：`cache/layout.json` 里 `"theme": "dark" | "light"`。
  **浅色底图必须配 `light`**，深紫卡片压浅蓝会像贴纸。

## 八、点歌怎么写

观众在弹幕里打：

```
点歌，歌名，歌手（可不选）
```

需要 `player/player.html` 一直开着（最小化可以，关掉就没声），
并且点过一次「启动」解锁浏览器的自动播放策略。

## 九、常见问题

**网页打不开** → 看 `18082`。控制台没起来，双击 `start.cmd`。
**网页能开，点开播没反应** → 看 `18081`。桥没起来，控制台里点「启动」。
**画面秒退，报 `No module named 'PIL'`** → Python 缺 Pillow。
注意 Windows 上 `python` 指哪个取决于父进程的 PATH，cmd 里和 bash 里可能不是同一个。
**画面在，但不刷新** → 看 `overlay.log`；判断画面活没活看 `overlayAgeMs`，不要看 pid。
**点歌没反应** → 先看播放器页面开着没、解锁没；再看取流有没有失败。
**改了 `render.py` / `bridge.mjs` / `server.mjs` 没生效** → 这三个要重启。
`layout.json` / 各个 `.html` 不用。

## 十、说明

- 「开始直播」那一下只能你自己点，脚本不碰账号和实名信息。
- 弹幕来源是抖音官方能力的封装（`douyin-mcp`），需要单独准备，
  路径用 `--mcp <路径>` 或环境变量指定。
- 这套东西是为单人自用写的，没有多房间、多用户的设计。
