# 2026-10-30 数学与高难问题：都不开思考

## 结论先说

**两种都不开思考，只调字数。** 中间试过给高难问题单开一档 `thinking`，
能答准，但 `max_tokens` 要提到 900+、耗时翻几倍，主人判断不值，撤了。

| 类型 | 例子 | 字数 | 思考 | 处理 |
|---|---|---|---|---|
| 小学算术 | `123乘456` | 20 | 关 | **不特殊处理**，算对算错随它 |
| 高难问题 | `黎曼猜想`、`费马大定理`、`微积分` | 40 | 关 | 多给字数 + 一句引导 |
| 日常聊天 | — | 20 | 关 | 老路 |

## 为什么小学算术故意不管

主人原话：「数学别管了，装蠢乱回答了，这样还能防止别人乱消耗 token」。

装蠢本身就是防线：观众拿她当计算器刷，答不准就没人刷了。
真给她做本地四则运算，等于免费送算力。**这条已经否掉两次，别再提。**

顺带一个观察：算对算错是模型的随机性，没有特殊处理时**有时对有时错**——

```
123乘456 → 五万六千零八十八诶        （对了）
123乘456 → 我算算，五百六……诶等等      （错了，还被截断）
```

两种都出现过。这就是「不管」的真实状态。

## 高难问题：只做两件不花钱的事

### ① 字数放到 40

黎曼猜想用 20 字说不清。实测要 19~34 字才够，所以走 `MAX_LEN_DEEP`，
由桥用 `speakSplit()` 拆两段念。

判据 `isHardQuestion()`：

```js
const HARD_Q_RE = /黎曼|哥德巴赫|费马|庞加莱|四色定理|千禧|孪生素数|柯拉茨|P=NP|NP完全|
  微积分|定积分|不定积分|微分方程|矩阵|拓扑|群论|素数|质数|对数|复数|虚数|导数|
  量子|相对论|黑洞|薛定谔|弦论|暗物质|反物质|猜想|定理|悖论|证明|推导|
  哲学|存在主义|形而上学|意识是什么/
```

误伤可接受：「定理」「证明」出现在玩笑里，也只是这条多说两句，不会答错。

### ② userLine 加一句引导（效果比什么都明显）

```
（这条是个正经问题：最多两句、40 字以内，把你知道的讲清楚，别一句就推掉。
拿不准的部分就说不准。）
```

没有这句的时候：

```
黎曼猜想是什么 → 这个我真不会，只知道是数学难题   （15 字，一句推掉）
```

有了之后（**不开思考**）：

```
黎曼猜想是什么 → 黎曼猜想是说黎曼ζ函数非平凡零点都在一条线上，我没细学，只能说个大概  （34 字）
费马大定理     → 费马大定理是说 xⁿ+yⁿ=zⁿ 在 n 大于二时没正整数解，我记了个大概        （37 字）
```

## 那次「开思考」到底试出了什么

值得记下来，免得以后又走一遍：

| 配置 | 黎曼猜想的回答 | 耗时 |
|---|---|---|
| 关思考 + 20 字 + 无引导 | 这个我真不会，只知道是数学难题 | 1.5s |
| **开思考** + 40 字 + 有引导 | 素数的分布藏着个规律，谁也没能证明出来 | 1.4s |
| **关思考** + 40 字 + 有引导 | 黎曼ζ函数非平凡零点都在一条线上 | 1.3s |

**开思考反而没更准。** 真正起作用的是那句引导和 40 字额度。

原因不难理解：`thinking` 吃的是 `max_tokens` 的额度，答这种「一句话说清是什么」
的问题帮不上忙；它擅长的是多步推理（解题、证明），而那种成果要被 `clip`
砍到 40 字，根本放不下。

所以撤掉是对的 —— 花了 token 没换来质量。

## 明确不做的

- 本地算四则运算（否掉两次）
- 接搜索（所有事实来自模型训练数据，「某某最近有新书吗」靠它自己说不知道）
- 开思考（就是这次撤的）
