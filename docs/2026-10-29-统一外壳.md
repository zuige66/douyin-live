# 统一外壳（2026-10-29）

## 为什么改

以前是五个各自独立的页面：`panel.html` 管开关、`settings.html` 管配置、
`editor.html` 管版式、`music.html` 管点歌、`home.html` 是个没人链的旧入口。

问题是**每个页面都有一套自己的导航**：panel 是卡片流，settings 是「返回箭头 + 11 个 tab」，
editor 是独立工具栏，music 是小窗。进去以后想换到另一个功能，只能先点那个 `←` 退回首页，
再猜它在哪。加上 settings 一页 1898 行、40 张卡片，找功能全靠滚。

这次不换技术栈（还是手写 HTML + 内联 CSS/JS，零构建、双击就跑），只补一个壳：
**左边一级菜单 + 顶部条 + 内容区**。

## 结构

```
index.html          外壳：左侧菜单 + 顶栏 + 多标签页 + 常驻播放器
  └── <iframe>      内容区，装原来的页面，页面代码一行没改
       ├── panel.html      控制台：开播 / 状态 / 日志
       ├── settings.html   6 组页签（账号/素材/形象/记忆/声音/诊断）
       ├── editor.html     画面版式：拖位置调宽度
       └── music.html      点歌台：队列 / 音源 / 在放什么
```

> 配色和圆角后来另开了一轮改（浅色 + Soybean 风格 + 顶部多标签页），
> 详见 `2026-10-29-浅色改版.md`。本文只讲结构。

`server.mjs` 的 `/` 现在发 `index.html`（以前发 `panel.html`）。
四个子页面还是照旧能单独打开，这是留着当逃生门的 —— 外壳出问题时能绕过去看。

> 名字提示：README 里提到的旧 `index.html`（2026-10-28 删掉的）是**画面叠加层**，
> 跟这个外壳不是一回事，别被那几段历史章节带偏。

## 路由

hash 路由，浏览器的前进/后退天然能用，刷新也停在原处。

> **2026-10-29 下午更新**：侧栏已经从「4 个一级 + 设置下 11 个二级」改成**扁平 9 项**，
> 设置页的 11 个 tab 合并成了 6 组。下面这张路由表是重排后的样子，
> 详细取舍见 `docs/2026-10-29-侧栏重排.md`。

| 地址 | 显示 |
|---|---|
| `/#/panel` | 控制台（默认） |
| `/#/settings/account` | 账号（= 账号 + 回复） |
| `/#/settings/media` | 素材（= 礼物 + 电脑） |
| `/#/settings/look` | 形象（= 形象 + 人格） |
| `/#/settings/memory` | 记忆（= 记忆 + 知识） |
| `/#/settings/audio` | 声音（= 音量 + 音源） |
| `/#/settings/diag` | 诊断 |
| `/#/editor` | 画面版式 |
| `/#/music` | 播放器（点歌台） |

`/#/settings` 不带组名就落「账号」。点页面里的 tab 时，左边菜单会跟着亮，
地址栏也换成那个入口的地址（用 `replaceState`，不新增历史）。

在同一页里换组只模拟点击、不重新加载 iframe（重载会触发整页重新取数）；
换到别的页才动 `src`。

## 播放器为什么搬到了外壳里（改之前先看这段）

`panel.html` 里原来有一段 `<audio>` + 每秒 `/client/poll`。它被整体搬到了 `index.html`，
`panel.html` 现在只负责显示音乐状态。

原因是硬的，不是审美问题：

> 桥靠 `/client/poll` 的**心跳**判断「播放器界面在不在」，超过 25 秒没心跳就回落本机 QQ 音乐
> —— 观众那边就是静音。而 iframe 换页会整页卸载，里面的定时器跟着停。

所以 `<audio>`、poll 循环、`/client/report` 上报这三件事，**只能住在一直可见的外壳文档里**。
以后谁想在子页面里再放一个播放器，会立刻打断心跳，别这么干。

出声仍然要用户点一次：顶栏那个「开启声音」（浏览器的自动播放策略）。
点过一次记在 `localStorage` 的 `zy-music-unlocked` 里，刷新会自己接上。

## 怎么加一页

1. 把新页面扔到项目根目录（跟 `panel.html` 同级）
2. 在 `index.html` 的 `PAGES` 里加一项：

```js
const PAGES = {
  // ...
  gift: { file:'/gift.html', name:'礼物', icon:'panel' },
}
```

3. 把 `gift` 加进 `ORDER` 数组（决定菜单顺序）
4. 要图标就在 `ICON` 里加一条 SVG，不加会空一块

`server.mjs` 不用动：`ALLOW_EXT` 已经有 `.html/.js/.css/.woff2/.svg`，
点开头的目录和 `llm.json` / `cookies.txt` 仍然 403。

## 两个必须知道的约束

**① 子页面里不能放"必须一直跑"的东西。**
iframe 切页就卸载，定时器、WebSocket、`<audio>` 全停。要常驻就放 `index.html`。
这条已经踩过一次了（就是上面的播放器）。

**② 外壳靠同源访问页面内部的 DOM。**
`index.html` 会在 iframe `load` 之后做三件事：

- 把页面里的 `a[href="/"]`（那个 `←`）改成切回控制台，避免「外壳套外壳」
- 把 `a[href$=".html"]` 的跳转接管成外壳路由，这样左边菜单会跟着亮
- 给页面里的 `.tab[data-tab]` 加监听，点 tab 时同步左边菜单和地址栏

都是 `try/catch` 包着的，失败了只是这几处增强失效，页面照样能用。
但这意味着**只能从 `http://127.0.0.1:18082/` 打开**，不能把 `index.html` 拖进浏览器
（`file://` 下同源判断不一样，iframe 里会被挡）。

## 退回旧版

`panel.html` 改动前的原样存了一份：`panel.html.bak-shell`。

要整体退回，把 `server.mjs` 里这一行改回去就行：

```js
if (rel === '/' || rel === '') rel = '/panel.html'
```

  大部分（权限 / i18n / 多标签 / CRUD 表格）在这个单人本机场景里都用不上。
  外壳这一层做完，如果以后还想升级，菜单结构可以原样搬到 Vue 里，不用重复设计。
