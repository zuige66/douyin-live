# 浅色改版 · 模仿 SoybeanAdmin（2026-10-29）

## 为什么改

上一版是「深色 Material 3 Expressive」：28px 大圆角卡片、胶囊按钮、15px 字号、
24px 卡片内边距。单看一页挺好看，但五个页面拼成一个后台之后：

- 卡片浮在深底上，一屏装不下几块，滚得远
- 按钮全是胶囊，主次不分（「启动」和「重启」长得一模一样）
- 状态用灰色小字跟在按钮后面（"在跑 19 秒"），扫一眼看不出哪组出问题了

参照物是 [SoybeanAdmin](https://soybeanjs.cn/function/tab)：**浅色 + 4px 圆角 + 1px 边框 +
紧凑行高**。它的默认值就是 `borderRadius: 4`、主色蓝 `#1890ff`。

## 现在的配色

主色用了 Soybean 官方默认的绿 `#18a058`（跟原来那套青绿是一条线，过渡自然）。

| 用途 | 变量 | 值 |
|---|---|---|
| 页面底 | `--bg` / `--surface` | `#f4f6f8` |
| 卡片 | `--surface-1` | `#ffffff` |
| 次级填充 | `--surface-2` | `#f7f9fb` |
| hover / 按钮底 | `--surface-3` | `#eef1f5` |
| 边框 | `--border` | `#e6e9ef` |
| 深边框 | `--border-2` | `#dfe4ec` |
| 主文字 | `--on-surface` | `#1f2225` |
| 次文字 | `--on-variant` | `#5c6470` |
| 弱文字 | `--muted` | `#8a94a6` |
| 主色 | `--primary` | `#18a058` |
| 主色 hover | `--primary-h` | `#128a4a` |
| 浅绿容器 | `--primary-c` | `#e9f7ef` |

| 危险 | `--danger` / `--danger-c` | `#d03050` / `#fdecef` |

尺寸：卡片圆角 6px、按钮/输入框 4px、标签 3px。正文 14px（原来是 15px），
卡片内边距 16×18（原来 24），行高 1.5。

**规矩照旧：只用纯色，任何地方都不许出现渐变。**

## 变量名没换，所以页面 CSS 不用重写

这是这次改动能一次推完的关键：`--surface` / `--surface-1..4` / `--primary-c` /
`--on-primary-c` 这些名字全部沿用，只是值换了一套。四个页面里所有
`background:var(--surface-1)` 之类的写法自动变浅。

**只有一处语义反了**：

> 深色版里 `--primary-c` 是深绿底 + 浅绿字（`#005143` / `#9bfbdf`），
> 浅色版里是浅绿底 + 深绿字（`#e9f7ef` / `#0e7a45`）。
> 用法没变（都是"弱强调容器"），但如果以后有人想加一个深绿实心块，
> 用 `--primary` + `--on-primary`（白字），别用 `-c` 那一对。

## 公共文件：`ui/theme.css`

五个页面都 `<link rel="stylesheet" href="/ui/theme.css">`，里面是：

- `:root` 全套变量 + `color-scheme: light`
- 基础 reset
- `input[type=range]` 的统一样式
- `.tag`（状态标签）、`.kv`（键值行）

**`color-scheme: light` 别删。** 少了它，浏览器会按深色渲染原生控件 ——
滑杆轨道会变成一条黑杠，滚动条也是深色的，在浅色页面上非常刺眼（踩过）。

各页面自己的 `<style>` 在 `<link>` 之后，所以页面内的规则优先级更高，
需要单独覆盖时直接写就行。

## 各页改了什么

### `index.html`（外壳）

- 白底侧栏 + 白底顶栏，激活项浅绿底深绿字
- **新增顶部多标签页**：打开过的页面停在顶栏，能关能切，刷新后还在
  （存 `sessionStorage` 的 `zy-tabs`）。最后一个关不掉。
- 顶栏音乐状态改成小圆点 + 文字

### `panel.html`（控制台）

这是结构动得最多的一页：

- 状态区从「六个浮起的 stat 卡片」→ **两列键值列表**（约省一半高度）
- 「分开控制」从「胶囊按钮 + 灰色小字」→ **三栏对齐行**：
  `组件名 | 按钮组 | 状态标签`
- 两个按钮合成 `.btngrp`：只有外侧有圆角，中间一条分隔线（Naive UI 的 ButtonGroup）
- 状态文字改成 `.tag`，颜色跟着状态走（在跑=绿 / 没跑=灰 / 进程在但没数据=黄）
- 顺带删掉了「去别的页」那张卡片（左侧菜单已经替代它）

### `settings.html`（设置）

- 11 个胶囊 tab → **下划线页签**（顶栏已经有一排标签了，再摆一排胶囊会打架）
- 32 处圆角统一收敛（脚本批量处理的，开关的胶囊形状单独跳过了）
- 分段选择器（回复档位那种三选一）改成浅槽 + 白底选中块

### `music.html`（音乐台）

- 卡片宽度 400 → 560，封面 92 → 76，标题 24 → 18
- 圆形播放键保留（播放器的惯例），尺寸 56/80 → 44/56
- body 从垂直居中改成顶部对齐 —— 在 iframe 里居中会让内容跑到下半屏

### `editor.html`（画面编辑器）

- 只改「工具外壳」，**画布里的配色一个没动**
  （`#stage` 那套 `--ink` / `--pri` / `--card` 是画面真实颜色，见文件里的注释）
- 工作区点阵背景 `#222b31` → `#d5dbe4`，画布阴影从 `rgba(0,0,0,.55)` 收轻

## 备份与回退

四个页面各存了一份改之前的样：

```
panel.html.bak-light
settings.html.bak-light
music.html.bak-light
editor.html.bak-light
```

回退单页就把 `.bak-light` 覆盖回去；整体回退还要删掉 `index.html` 里的
`<link rel="stylesheet" href="/ui/theme.css">`，并把 `server.mjs` 的 `/` 指回 `panel.html`。
