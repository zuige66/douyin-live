# 2026-10-28 晚 · 右上两卡 + 字幕条改版

主人原话：「右上角的两个板块能不能 ui 优化一下，跟现在的页面很不搭配，而且字体大小，
字体加粗什么的都很奇怪」「这个说话也是，『说话』这两个字去掉，然后同上处理」。

## 一、诊断（都能对应到代码）

| # | 现象 | 原因 |
|---|---|---|
| 1 | 白卡像贴在粉色背景上的贴纸 | 浅色主题 `CARD` 是纯白 `#FFFFFF`、`HAIR` 是 `#CAC4D0`，且浅色主题不画阴影 —— 卡片和背景几乎同亮度 |
| 2 | 「已回复」贴着卡片底边 | 高度是拍出来的 `32+36+3×46+10=216`，最后一行落在 182、字高 27 → 距底 7px；顶部却留 30px |
| 3 | 字号 8 档但没字阶 | 21/22/24/25/27/28/29/34 —— 标题 25 比正文 27 还小；「实时」22 夹在中间没有定位 |
| 4 | 数字不是重点 | 27px、不加粗、还分三种颜色（`PRI`/`TER`/`INK`），跟左侧标签同量级 |
| 5 | 分隔线在浅色主题下隐形 | `build_base` 里写死 `fill=(255,255,255,20)` —— 白卡叠白线 |
| 6 | 音柱歪 | 柱顶 `sy+4`、文字基线 `sy+2`，凑近看是斜的 |
| 7 | 「点歌格式」抢戏 | 28px 正文字色，跟歌名同级，说明书和内容分不开 |
| 8 | 暂停时像省略号 | 暂停态画 4 根 5px 小柱，排起来就是「……」 |
| 9 | 594 宽的卡里空 400px | 纵列「左标签 + 右数字」，宽度用不满 |

## 二、定下来的方向（主人三选一）

1. **玻璃卡片**：半透明白 + 亮白描边 + 玫红柔影
2. **本场数据横排三格**：数字在上、标签在下，靠大小分主次
3. **强调色跟背景红**：`PRI` 从 M3 紫 `#4F378B` → `#B0274A`

### 硬约束

PIL 只有 `msyh.ttc`（常规）和 `msyhbd.ttc`（粗）两档字重，**做不到 500/中等加粗**。
所以层级只能靠字号 / 颜色 / 留白，不能靠字重。所有尺寸都从 `CARD_PAD` 那几个常量推。

### 字阶（1920 画布 px）

| 角色 | 字号 | 字重 | 颜色 |
|---|---|---|---|
| 卡片标题 | 30 | 粗 | `INK` |
| 本场数据数字 | 48（窄卡自动收） | 粗 | `INK` |
| 数字标签 | 23 | 常规 | `DIM` |
| 正在播放歌名 | 34 | 粗 | `INK` |
| 队列歌名 | 28 | 首首粗 | `PRI` / `INK` |
| 辅助（直播中 / 首排队 / 歌手 / 点歌格式） | 21–22 | 常规 | `DIM` / `FAINT` |

### 版式公式

```
stats_geom(): ty=28, ny=28+42+22=92, ly=92+64=156 → h=156+30+28=214
songs_h():    28*2 + 42 + 14 + np_h + 条数*58 + 92
              np_h = 132（有歌手）/ 110（无歌手）
              3 首时 = 510
```

## 三、改了什么

### `native/render.py`

- `_PALETTE` 新增三把键：`HR`（卡片内分隔线）、`TIPBG`（点歌格式小底）、`SHADOW`（柔影颜色，`None` = 不画）。
- 浅色主题：`PRI #B0274A`、`TER #963A54`、`CARD rgba(255,255,255,0.80)`、
  `HAIR rgba(255,255,255,0.94)`、`SHADOW (128,34,66,54)`。
- **深色主题一个字没动**：`CARD` 仍是不透明 `#2E263F`、`SHADOW=None`，`HR`/`TIPBG` 取等效值。
- `shadow_patch()` 加 `color` 参数（原来只能画黑影，压在粉底上发脏）。
- `build_base()` 里新增局部函数 `card(x,y,w,h)`：柔影 → 玻璃底 → 亮描边，**一律画在 `lay` 这个 RGBA 层上**
  （RGB 图上 fill 带 alpha 会被丢掉，这个坑代码里已经记过一次）。
- 本场数据：横排三格、格内居中、标题 `INK` 加粗，「实时」换成红点 + 「直播中」。
- 点歌台：标题 `INK` 加粗；音柱底边 `sy+26` 对齐文字中线；暂停态改成一条横线；
  分隔线走 `HR`；「点歌格式」包进 `TIPBG` 小底。
- `comp_h()` 拆出 `stats_geom()` / `stats_h()` / `songs_h()`，绘制与测高共用一套数。
- `compose()` 数字：千分位、`INK`、**按格宽自动收缩**（卡片拖到 397 时每格 113px，
  48 号的 `1,284` 有 134px，会压到隔壁格；三个数字用同一字号，取最宽的那个试）。
- 字幕条：去掉「说话」标签，按内容收窄后居中，`mm` 锚点垂直居中，玻璃底 + 柔影 + 亮描边。

### `editor.html`

- 浅色主题 CSS 变量同步（`--pri/--ter/--card/--hair`，新增 `--hr/--tipbg`），
  浅色下给 `.card` 和字幕条补 `box-shadow`。
- `H_()`：`stats 216→214`、`songs 478→510`。
- `htmlOf()` 的 stats / songs 预览按新坐标重写，**不再乘 `k`** ——
  真画面的内边距是固定像素，不跟卡片宽度缩放；乘了 `k` 之后 594 宽的卡在预览里会松一大截。

## 五、注意事项

- **改完必须重启画面窗口**（`open-overlay.cmd`）才生效 —— 跑着的是 `pythonw overlay.py`，
  进程里是旧代码。
- 卡片的位置 / 宽度仍然由 `cache/layout.json` 决定，这次没动任何坐标。
  想统一宽度就在编辑器里拖右边框，或直接改 json 里的 `w`。
- 数字字号下限 26，宽度再窄（< 300）就只能截断视觉上会偏小，那时建议在编辑器里把卡拖宽。
