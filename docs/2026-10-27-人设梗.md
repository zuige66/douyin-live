# 人设加梗（2026-10-27）

> 主人原话：「要大肥鱼有梗一点：蔡徐坤的小黑子……科比的 man 曼巴……还有一个蛊真人的魔怔大肥鱼」。
> 这份记的是**加了什么、为什么这么加、哪些不能加**。改之前先看最后一节「红线」。

## 一、定了两件事

| 项 | 定的是 | 理由 |
|---|---|---|
| 浓度 | **中度**：十条回复顶多两条带梗 | 轻度几乎看不出「有梗」；放飞短期切片强，长播容易腻，且更容易踩平台词库 |
| 落地范围 | **人设卡 + 本地话术** | 只改人设卡的话，模型一挂她就退回「嗯嗯，我在听」，观众立刻感觉「变机器人」 |

## 二、改了两个文件

### 1. `prompts/dafeiyu-live.md` —— 新增「你的梗」一节

给模型看的。位置在「你在直播间里怎么待着」之后、「❌/✅ 对照表」之前。

内容结构：
- **五条规矩**（只接不抛 / 一次一个 / 别连庄 / 软着说 / 该收就收）
- 三组梗 + 触发词 + 台词清单 + 一条 ❌ 红线
- 一组通用梗

顺带加了两条铁律：

- **句尾不加句号** —— 字幕条不需要，TTS 会多停一下，而且 20 字里白占一位
- **一句就收** —— 梗说完就停，别接下半句解释，接到 20 字被砍掉比不接还难看

### 2. `reply.mjs` —— 新增 `MEME` 表 + `pickMeme()`

给「模型挂了」这一档用的。关键词直出，零延迟。

- 命中第一条就 `return`，不往下走
- **必须排在 `RE.ai` 之前**：`RE.ai` 里有 `真人`，「蛊真人什么时候更新」会被当成
  「你是不是真人」截走 —— 实测回了一句「怎么突然问这个」，梗全丢。
  反过来不误伤：`MEME` 里没有裸「真人」，纯问「你是真人吗」照样走 AI 那一支。
- 蛊真人那组带 `sub`：问「什么时候更新」回「你把青春还我」，问「大爱仙尊」回
  「唯我独尊」，免得驴唇不对马嘴
- 通用梗**一条一条分开**：合并成一组时，「退退退」会随机回「格局小了」
- `pickMeme()` 记最近 4 条，同一句不连着出

## 三、梗库全表

### 小黑子（蔡徐坤）

触发：小黑子、ikun、i坤、坤坤、只因、你干嘛、背带裤、铁山靠、油饼、树枝

- 诶哟你干嘛，嗨嗨
- 只因你太美，我唱不来
- 小黑子，我可是正经小鲸鱼
- 食不食油饼，我食
- 篮球我不打，我只会游
- 律师函警告哦，开玩笑的

### 曼巴（科比）

触发：man、曼巴、manba、牢大、凌晨四点、what can i say

- Man，what can I say
- 曼巴精神，凌晨四点我还在睡
- 牢大，这球我真不会打
- 你喊 man，我就得接这句

### 蛊真人（魔怔形态）

触发：蛊真人、大爱仙尊、方源、春秋蝉、魔怔、蛊批、至尊蛊

设计成**短暂走神**：念一句，然后自己回来。「走神」本身就是笑点，
比一本正经背台词好笑。

- 人生在世，当如蛊……我刚说什么了
- 春秋蝉，转——诶，我怎么又念这个
- 大爱仙尊，唯我独尊
- 蛊真人，你把青春还我
- 我是蛊批，我魔怔了
- （按场合细分：更新 → 还我青春；大爱仙尊 → 唯我独尊；方源 → 方源来了都得摇头）

### 奶龙（第二批加，主人点名）

触发：奶龙、龙龙、傻龙

她俩都是圆滚滚的一只，学起来不违和 —— 但她是鲸鱼不是龙，所以每次都留个
「不对」的拐弯，笑点在这个拐弯上。

- 奶龙，启动！
- 我是奶龙……不对，我是鲸鱼
- 奶龙和鲸鱼，都是圆滚滚的
- 嗷呜，奶龙来了
- 奶龙不知道哦，奶龙只是条鱼

### 通用（第二批补齐）

| 触发 | 回什么 |
|---|---|
| 牢弟 / 牢妹 | 牢弟，你这波不行 / 牢弟别急，慢慢来 |
| 要哪个 / 选一个 / 二选一 | 我全都要 / 小孩子才做选择 |
| 全都要（观众自己说的） | 都给你 / 贪心，我喜欢 |
| 不要过来 / 别过来 / 你过来啊 | 你不要过来啊 / 别过来，我害怕 |
| 谁懂 | 家人们谁懂啊 / 谁懂啊，我太难了 |
| 站谁 / 帮谁 / 支持谁 | 这波我站你 / 我站你，别怕 |
| 这波我站 / 我站你（观众支持她） | 呜，你真好 / 那我就不怕了 |
| 贴贴 | 贴贴 / 过来贴贴 |
| 抱抱 | 抱抱 / 来，抱一个 |

**为什么要拆成「问」和「说」两套**：观众问「你选哪个」，她答「我全都要」是好梗；
观众自己说「我全都要」，她再回一句「我全都要」就是复读。
「站谁」同理 —— 问「你站谁」她站队，说「我站你」她就得道谢。

早期那批：急了 / 太典了 / 你个老六 / 破防了 / 退退退 / 格局小了 / 尊嘟假嘟 / 显眼包。

## 四、红线（台词是按这个筛的，改的时候别手滑）

| 谁 | 不能碰 | 为什么 |
|---|---|---|
| 蔡徐坤 | 骂人、「娘」、「鸡你太美」 | 前两个是人身贬损，第三个是带侮辱的谐音。只玩原声那几句 |
| 科比 | 直升机、坠机、死亡、复活赛 | 这不是梗，是别人的命。抖音这类地狱笑话一封一个准 |
| 蛊真人 | 「解封」、提作者、引战 | 书是下架状态，喊解封容易被判低质或引战。说「更新」「还我青春」就够 |

还有一条通用的：**有人在难受、在问正事、在讲规矩时，梗全部关掉**。
这条写在「什么时候要收着」里，加了「一个梗都不许带」。

## 五、踩过的三个坑

1. **「真人」被 AI 规则截走** —— 梗必须排在 `RE.ai` 之前，否则「蛊真人什么时候更新」
   会被当成「你是不是真人」，回一句「怎么突然问这个」。
2. **模型会把两句梗拼成一句** —— 说「奶龙」，它回「奶龙，启动！我是奶龙……不对，我是鲸鱼」，
   十九个字糊在一起。人设卡原来只写「一次一个」，不够硬；改成
   「下面每组是**备选**，不是台词本，一次只挑一句」之后才老实。
   **这条对所有梗都成立，别删。**
3. **模型层没有去重，会复读** —— 已修（当天下班前）。
   连发三条「奶龙」，三次都是「奶龙，启动！」（本地话术有 `pickMeme()` 管最近 4 条，模型层没有）。
   修法：`rememberSaid()` 记最近 3 句**说出口的话**（不管模型说的还是模板说的），
   `saidHint()` 拼在这条 user 行尾巴上「你刚才说过…，别重复，换一句」。
   **只能放 user，不能放 system** —— 塞 system 等于前缀每条都变，缓存当场归零。
   实测：四条「奶龙」→ 四个不同说法，缓存命中 91.9% 没掉。
   出口统一在 `makeReply()` 外壳记（内层 `makeReplyRaw()` 有六七个 return，逐个加必漏）。

## 八、怎么调

- **觉得梗太少**：改人设卡「你的梗」标题下的密度（十条两条 → 五条两条），
  再在 `MEME` 表里补几句
- **觉得梗太多**：先把通用那八条删掉，只留三组主梗
- **不想要某个梗**：从 `MEME` 里删那一项 + 人设卡删对应台词，**两边一起删**，
  否则模型在时还接、模型挂时不接，表现会飘
- **改完记得**：人设卡改了要**重起弹幕桥**（热重载还没做，见优化方案 P1-4）
