# prompts/ —— 人设、知识库、皮套

这个目录里的东西**不进公开仓库**（`dafeiyu-live.md` 已在 `.gitignore` 里）。
clone 下来是空的，要自己补。

## dafeiyu-live.md（主角色卡）

`reply.mjs` 的 `PERSONA_FILE` 就是它。**缺了也能跑** —— 会自动回退到
`reply.mjs` 里内置的 `FALLBACK_SYSTEM`（一段八行的人设），但很薄，
模型容易漂：实测会漂成「否认自己是 AI」和乱叫「宝宝」。

补法：在 `prompts/` 下建 `dafeiyu-live.md`，最小可用格式：

```markdown
<!-- persona: my-live -->
# 角色卡

## 你是谁
你是「<名字>」，<一句外观描述>。

## 铁律
- 一句话说得完，20 个汉字以内（要过 TTS，太长念不完）
- 称呼直接用昵称或「你」，不要「宝宝」「亲爱的」
- 不用 emoji，不用括号写动作
- 被问是不是 AI：承认，用玩笑带过

## 说话风格
...
```

- 第一行的 `<!-- persona: xxx -->` 是身份牌，`reply.mjs` 会把它剥掉再喂给模型，别删。
- 改这个文件**不用改代码**，也不用重起桥 —— 按 mtime 热重载，下一条弹幕就生效。

写卡的经验（踩过的）：

- **长度要压到 TTS 念得完**。写成长篇，她会一口气念十秒，观众听不下去。
- **正反对照表比形容词有用**。「别太活泼」没用；写「× 哇啊啊好开心！／√ 今天人有点多」
  模型才学得会。
- **外观别写死在主卡里**。换皮套时她会说错发色 —— 外观放进 `prompts/skins/<皮套名>.md`，
  按当前皮套注入。主卡只管性格。

## skins/ —— 每套皮套一份

`prompts/skins/<皮套名>.md`，皮套名对应 `cache/layout.json` 里
`items.character.pet`。丢一个新 md 进去就自动认出来，主卡一个字不用改。

写「外观 / 自称 / 这一身对应的身份」。这是 `reply.mjs` 里 `loadSkin()` 读的。

## kb/ —— 知识库

`prompts/kb/*.md`，一份 md 一个库，丢进去就自动认出来（设置页「知识库」那栏能看到）。

每个 `## ` 块带一行关键词注释，命中才注入：

```markdown
## 你的直播时间
<!-- kw: 什么时候播,几点播,直播时间 -->
每天晚八点到十一点，周末不一定。
```

关键词要写观众**真的会打**的说法（口语、错别字都行），不是书面词。
