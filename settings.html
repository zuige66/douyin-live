QQ 音乐 · 粘贴 Cookie

扫码这条路只能拿到「基础登录态」（uin 有了，会员票据没有），会员曲照样取不到音源。 要放 VIP 原唱，得从已经登录的浏览器里复制一整条 Cookie。
1. 浏览器打开 y.qq.com，确认右上角是你的会员账号（已登录）
2. 按 F12 → 切到 Network → 刷新页面 → 点任意一个请求
3. 在 Request Headers 里找到 Cookie:，把冒号后面那一整行复制下来
4. 粘到上面的框里，点「保存」
关键的键是 qm_keyst；只有 uin 的话会员曲还是放不了。
